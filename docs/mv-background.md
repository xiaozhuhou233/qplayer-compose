# 网易云 MV 动态背景

设置 → 外观 → **MV 动态背景（实验性）**，默认关闭。开启后，仅播放详情页使用 MV：优先请求 1080p，不可用时尝试 720p，静音循环视频正中间的约 24 秒，短于 24 秒则循环完整视频。当前按时间中点选段，不进行内容或副歌识别。画面恢复等比铺满整页、居中裁切，保持原始宽高比。视频尺寸回调、预加载播放器接管和视口尺寸变化时都重新计算变换，首帧只在源尺寸已知后显示。

当前歌曲在 MiniPlayer 阶段即预取 MV 地址并 prepareAsync 预热静音原生播放器。预热不创建分离纹理、不开始播放；详情页始终使用 TextureView 自己创建和消费的 SurfaceTexture，再绑定预热播放器并定位中央片段。避免跨 View 转交纹理和手动覆盖帧监听器造成只有一帧、后续不刷新的问题。首次网络请求或缓冲仍需时间，等待时显示原封面的模糊背景而非纯黑。无 MV 或加载失败时保持原封面。歌词页沿用原背景，已准备的 MV 暂停并隐藏，返回详情时复用。视频独立于音乐进度，不播放 MV 音频，也不申请音频焦点；暂停、继续以音乐播放器的即时状态为准。

## 接口

- 歌曲详情：WEAPI `/api/v3/song/detail`，参数 `c: [{id: songId}]` 的 JSON 字符串，读取对应歌曲的 `mv`（兼容 `mvid`）。不按歌名搜索，以免配错视频。
- MV 地址：WEAPI `/api/song/enhance/play/mv/url`，参数 `id: mvId, r: 1080`（空地址时尝试 `720`），读取 `data.url`。实际画质由平台可提供的资源决定。
- 如需完整 MV 详情，参考接口为 WEAPI `/api/v1/mv/detail`，参数 `id: mvId`；本功能无需额外请求此接口。

已核对 api-enhanced 的 [mv_url.js](https://github.com/neteasecloudmusicapienhanced/api-enhanced/blob/main/module/mv_url.js) 与 [mv_detail.js](https://github.com/neteasecloudmusicapienhanced/api-enhanced/blob/main/module/mv_detail.js)。沿用应用现有网易云加密传输与会话，不依赖额外 API 服务。

## 回退及资源管理

首次视频帧出现前保留原背景。无 MV、权限不足、网络超时或解码失败时保持原背景，不弹出打断播放的错误提示。缓存只存在内存中，最多 48 首；播放地址缓存 10 分钟，无 MV 缓存 6 小时，异常不按无 MV 长期缓存。

暂停音乐时暂停视频，包括首次定位和循环定位未完成时；定位回调只在音乐仍播放时恢复视频。通过实际视频进度检查片段结束点，不使用独立运行的片段倒计时。退出详情页时释放该页面的播放器和输出纹理，根预热器可准备一个空闲播放器，闲置最多 90 秒；后台与歌词页暂停视频，回前台不增加会话编号或主动重建播放器。关闭开关、切换 B 站或最低配模式、根组合销毁时释放空闲资源。MV 下使用白色进度条保证可读性。

AndroidView 负责视频 View 的创建和最终释放，不复用已经 dispose 的 View。仅预热播放器可从预热容器转交给当前 View；SurfaceTexture 始终由当前 TextureView 管理，不手动安装或清除其帧监听器。网络、解码或首帧超时失败后自动重试（2、5、15 秒，之后间隔 30 秒），刷新 CDN 地址；离开详情页即取消重试，明确无 MV 的歌曲不重试。暂停状态进入页面时仅静音解码一个片段预览帧后停止，不恢复音乐。首帧由实际纹理更新确认，避免透明图层跳过绘制导致一直等不到画面。

通过 256×144 的原始解码帧检测编码自带的上下、左右黑条，支持超宽 MV 和不对称边框。暗场只需少量可见主体即可识别，不再要求中央三分之一大面积明亮；纯黑和无法确定边界的帧不裁切，并在后续帧有限重试。按剔除边框后的有效画面等比铺满视口，平移范围同样限制在有效画面内，避免拖出黑边，不压扁画面。`work/mv-wide-queue/Test-MvWide.ps1` 覆盖暗场、超宽、不同屏幕方向、上下平移与截图样本。

阴影恢复为根据标题和进度条位置逐渐加深的下部渐变，底部黑色不透明度约 99%，上部画面无遮挡。MV 模式取消控件下方局部圆形阴影，避免在整片渐变上叠出斑块。阴影保留在背景采样层中，不与玻璃控件形成自采样循环。

MiniPlayer 的显示／隐藏、展开／收回统一使用慢起步、中段加速、末尾减速的三次贝塞尔曲线。播放页形变和封面飞行共用已缓动的进度，封面不再次缓动；低配模式仍跳过动画。

Activity 允许背景绘制到显示缺口与状态栏区域（API 28+ SHORT_EDGES / API 30+ ALWAYS），关闭系统状态栏对比度遮罩。视频层不消费安全区；标题和控件仍通过 statusBarsPadding / navigationBarsPadding 避开系统栏。
