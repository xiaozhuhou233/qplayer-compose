# iOS 模式 / MusicOne 页面移植

入口：设置 → 外观 → iOS 模式。复用现有 `iosDesign` 持久化设置，与 Claude 界面互斥；关闭后按现有设计设置显示。播放引擎、网易云账号、AI 推荐和收藏数据继续使用 QPlayer 原有实现。

参考源码来自用户提供的 `MusicOne-main.zip`，Copyright (c) 2026 ShuyunR，MIT。许可证随 APK 放在 `assets/licenses/musicone-LICENSE.txt`。

| 参考实现 | QPlayer 接入 |
| --- | --- |
| `PlaylistIntroduction`、`PlaylistPlaybackActions` | 全宽正方形头图，底部 35% 渐隐；居中 28sp 衬线标题、13sp 副标题；48dp 随机／播放／排序按钮 |
| `MusicTrackRow` | 64dp 封面、16dp 圆角；标题 14sp、副标题 11sp、来源 10sp；原有长按菜单和加入队列 |
| `RecommendationScreen`、资料库卡片 | 原有索引绑定的搜索／排序结果；两列歌单卡片，保留创建／收藏分类和长按删除确认 |
| `ArtistIntroduction`、`ArtistAppearance` | 沉浸头图、主色采样、64dp 圆头像、30sp 名称、简介阅读与播放；吸顶歌曲／专辑分类 |
| `PhoneExpandedPlayer`、`PlayerCoverStage` | 最大 440dp 的等比大封面、12dp 圆角；22sp 标题、16sp 可点击歌手；复用封面共享飞行动画 |
| `ImmersivePlaybackControls` | 5dp 细进度条；上一首／播放／下一首、随机／循环；底部歌词和队列入口 |
| 原版 QPlayer `IosDesignTheme` | 恢复蓝色强调、白／黑背景和系统 iOS 对比色 |

平台字体使用现有系统字体与 Serif，不引入 MusicOne 的播放引擎、QQ 网络层或大体积字体资源。参考项目没有的多张歌手背景不伪造；网易云当前返回的歌手封面、介绍、热门歌曲和专辑直接接入。

MV 设置继续生效：有 MV 时移除大封面并使用全屏视频渐变背景；歌词页保留 QPlayer 歌词实现。B 站播放使用现有视频槽、进度与收藏入口。

## 共享元素与旧版控件恢复

- 直接移植 MusicOne `PageMotion`、`GestureAnimationHandoff`、`PageMotionSpecs`、`PlaylistCoverHandoff`，保留布局稳定后捕获锚点、可中断反向、手势速度延续、旋转尺寸变化归位和终点保留一帧再交接。
- 歌单／专辑使用实体封面锚点、统一 progress 驱动页面揭露与独立飞行画布；封面圆角和底部渐隐随 progress 同步。目标最多等待 160ms 布局，不等待网络。封面尚无图像时保留占位，不阻止导航。进入 420ms、返回 320ms。
- 播放器使用 MusicOne 480ms／360ms 曲线及拖动归位弹簧，与实际 MiniPlayer／详情封面的实测位置连接。iOS 页面下拉直接驱动同一转场进度。
- 从 `android-shell` 原样编译指定的 iOS 文件和 `com/kyant/backdrop`，包括导航栏、收缩 Dock、玻璃材质、交互高光、按钮、滑块、开关、对话框和播放页头部／控制条。只有路由、播放器状态和封面加载做 MD3E 适配；不编译旧 Activity、QML 引擎和 ONNX。
- MiniPlayer 恢复原版 48→44dp 玻璃胶囊、32dp／8dp 圆角封面、上下首和暂停按钮、600ms 延迟跑马灯、切歌封面淡入淡出、触觉反馈和收缩时按钮宽度／透明度联动；导航栏恢复原版拖动选中玻璃效果。设置和长按歌曲等弹窗在 iOS 下走原版玻璃对话框。
- 通用 Button、OutlinedButton、TextButton、IconButton 和 FilledIconButton 在 iOS 下统一调用旧版玻璃控件；歌单随机／排序、B 站全屏播放和设置分类／选项也走同一入口。非 iOS 的 FilledIconButton 保留原有颜色、形状和交互参数。
- 删除歌单详情页额外的悬浮搜索按钮；保留列表内搜索。歌手页面明确提供亮色 LocalContentColor 和 LocalTextStyle，避免继承外部浅色主题的黑字。
- 原版 Backdrop Apache 2.0 和 BiliPai GPL 3.0 文本随 APK 保留；MusicOne MIT 许可继续保留。

回归：`work/ios-motion-restoration/tests/Verify.ps1` 覆盖延迟布局、动画反向、手势归位、重复导航和窗口改尺寸。MV 原生解码和 GPU 材质仍需要实机视觉确认。

顶部控件恢复 `IosFloatingPageActions`：主页展开，其他页面收成队列按钮，长按队列展开，切换路由复位；用户上滑 10dp 隐藏、下滑 10dp 恢复，滚过 60dp 后渐显顶部阴影。主页滚动 24dp 驱动 Dock 收缩。控件绘制为录制页面的兄弟节点，避免采样自身导致 RenderNode 循环。封面头图延伸到状态栏，普通列表预留顶部阅读空间。

按钮兜底背景和按压高光遵守圆形／胶囊轮廓，不再出现方形覆盖层。对话框保留玻璃与圆角，增加 90% 明暗底色、背景遮罩及稳定文字颜色；正文 16sp／24sp 行高，操作按钮明确使用强调色或 onPrimary，避免 MV 和封面改变文字对比度。

2026-10-17：iOS 顶部不再由固定留白占据页面；主页和搜索的顶部阅读空间改为随列表滚走的 contentPadding。顶部保留原版按钮组和滚动渐变阴影。玻璃继续直接编译旧版 BiliPaiGlassParameters／IosGlassPalette，4dp 模糊、1.5 饱和度、0.40 底色和原版折射／阴影参数不另写近似值，折射开关接回设置。播放／歌词背景独立录制，控件为兄弟节点，防止 RenderNode 循环。

iOS 播放页最后一行保留原版随机／循环／收藏胶囊，删除重复的底部歌词／队列入口；顶部切页和队列入口保留。歌单详情长按封面或标题确认收藏／取消收藏，删除独立收藏和刷新按钮；资料库删除刷新按钮，原有长按删除逻辑保留。歌手页移除重复小头像。外观统一为 Claude／MD／iOS 三选一，仍兼容原有持久化开关。吉祥物的运行不再由会锁存的页面性能降级标记控制，仍遵守最低配、系统关闭动画和应用前后台状态。

歌单和歌手详情头图不再预留顶部空白，直接绘制到悬浮按钮之后；其他列表的阅读留白保持随内容滚动。两类详情页共用封面主色背景和完整的文字、按钮配色，不再使用纯白歌单背景。歌手简介由弹窗自身滚动，不在无界滚动容器内嵌套 LazyColumn。

玻璃背景录制更新后，通过合并到下一帧的通知，仅重绘依赖该背景的玻璃节点；组合背景同样转发通知，卸载时取消订阅。玻璃前景和明暗底色改为对实际区域采样的亮度响应，共用限流和 5×5 缩略图；采样不再等待一秒颜色动画结束后才继续。BiliPai 折射参数保持原值，弹窗保留原材质时序。页面内容和悬浮玻璃仍分层，避免自身采样。

三种界面模式共用同一个 AI 输入和根级展开宿主：键盘发送／回车从输入框展开，点击吉祥物打开随机偏好推荐，长按进入或退出持续 AI DJ 模式。生成状态不绑定首页的生命周期。

2026-10-17：播放列表独立移植 MusicOne `PlayerQueueSheet`、`QueueRow`、`QueuePlayingIndicator`，统一应用到 Claude／MD／iOS。保留原版 80% 屏高的可下拉关闭底部弹层、`#242629` 深灰背景、38×4dp 拖动条、23sp 标题、序号、46dp／16dp 圆角封面、15sp／12sp 歌曲信息、10% 白色当前行和三条音量动画。进入时定位当前播放歌曲，暂停时音量条回落。弹层自行负责进出动画，删除原先叠加的全屏队列转场。

QPlayer 适配位于 `Md3eMusicOneQueue.kt`，不引入参考工程的播放引擎或账号层。原有重复歌曲的队列项身份、点击播放、移除和排序仍接真实播放队列：长按歌曲拖动，或直接拖动右侧手柄；更多菜单提供添加、上移／下移和移除。列表截住滚动到边界后的剩余位移和惯性，排序期间禁止弹层拖动；弹层仍可从标题／拖动条区域下拉关闭。B 站相关推荐／合集切换保留。定时器固定在列表下方，仍使用根级 `Md3eSleepTimerState` 和原有 1–120 分钟、停止滑动后计时、到时暂停逻辑，关闭弹层不会取消计时。弹层使用 MusicOne 深色方案和系统字体，三种模式不再各自覆盖它的控件样式。
